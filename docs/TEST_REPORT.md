## 已覆盖场景

- 空输入、非法 IPv4、前导零、超出 0–255。
- 完整 IP 100% 重复。
- 75%、50%、25%、0% 逐段相似。
- 比较严格限定在同一条历史记录，禁止跨记录拼接。
- 星舰会员 10 次共享额度与 PRO 无限额度的基础逻辑。
- 自然月到期：普通月份、月末和闰年。
- 到期前一天提醒时间。
- BEP20 金额转最小单位与 transfer calldata。
- USDT / USDC 默认 BSC Token 配置。
- 本地版普通用户、备用管理员、总管理员权限边界。

## 代码级验证

- IP 查询在写入数据库前生成查重结果，首次查询不会命中自身。
- `full_ip + exchange` 联合唯一键允许不同交易所保存相同 IP。
- 5 秒防重复提交同时阻止重复扣额度、重复写计数和重复调用日志。
- 所有管理经营数据接口调用 `requireAdmin`。
- 星舰 / PRO 统计排除管理员账号和已删除用户。
- 收款指标只统计 `PAID` 订单。
- 订单状态使用条件更新抢占，避免并发验单重复开通会员。
- Transaction Hash 有数据库唯一索引。
- 后台支付进程会将过期订单标记为 `EXPIRED`，永久不匹配标记为 `REJECTED`。

## 上线前必须完成的环境测试

以下项目依赖真实 PostgreSQL、BSC RPC、域名 HTTPS 和钱包环境，不能只由离线单元测试代替：

1. 使用小额真实或隔离测试订单验证 MetaMask、WalletConnect、USDT、USDC 全流程。
2. 分别验证错误金额、错误 Token、错误地址、重复 Hash、过期订单和不足确认数。
3. 在目标香港服务器执行数据库迁移、备份与恢复演练。
4. 使用两台真实设备验证首次绑定、拒绝异机登录、管理员解绑和重新绑定。
5. 导入目标规模数据后执行数据库 `EXPLAIN ANALYZE`，确认 A/B/C/D 索引命中和 P95 响应时间。
6. 使用反向代理启用 HTTPS 后检查 `TRUSTED_ORIGIN`、Cookie Secure、CSP 和 WalletConnect 网络访问。

在上述真实环境验证完成前，不应把系统描述为已通过支付安全审计。
